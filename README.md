# 收获：遗产
> "我很敬佩第一个从草里打出种子的人——说不定那是小麦种子呢。"

当人们第一次从草丛中收获小麦种子时，可曾想过：真的只有小麦种子吗？将种子播撒入土时，可曾思考过：种植的方式只能如此吗？
疑问一旦生根，思考便无法停止。后人在草间发现了先人留下的遗产：形态各异的种子、分门别类的种植技艺。
这份遗产诉说着：观察每一颗种子，培育每一份生机，将它们种植在最适宜的土地上，你将收获一片大好河山。
这一次，打草收获的，不止是小麦种子。

(意义不明 草. 看似情怀, 实则游玩恶心人)
